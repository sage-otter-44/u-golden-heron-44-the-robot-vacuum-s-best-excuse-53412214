One line, 136 characters: the funniest excuse a robot vacuum gives for missing a spot.

> My lidar scanned the dust bunny under the couch, classified it as a sleeping pet, and I have been quietly respecting its nap ever since.

The joke is built the way the winners do it: one concrete scene from the vacuum's own world (its lidar misreading a dust bunny as a pet) with the turn landing on the last clause — the machine isn't lazy, it's being polite to a nap.

## How it works

`main.ts` writes the entry text to `/output/entry.txt` and guards the 140-character gate first: it throws if the text is empty or over 140 characters.

```sh
node main.ts
```
